# CRUD Mahasiswa (React)

Project: simple CRUD application to manage mahasiswa (students) built with React.  
Tugas untuk mata kuliah **Pengembangan Aplikasi Web**.

## Ringkasan
Aplikasi ini memperlihatkan operasi dasar Create, Read, Update, Delete untuk data mahasiswa (NIM, Nama, Jurusan).

## Fitur
- Tambah mahasiswa
- Edit mahasiswa (form terisi saat edit)
- Hapus mahasiswa
- Tampilan daftar mahasiswa dalam tabel

## Teknologi
- React
- JavaScript
- CSS (file App.css)

## Struktur folder (inti)
- src/
  - components/
    - StudentForm.js
    - StudentList.js
  - App.js
  - App.css
  - index.js
